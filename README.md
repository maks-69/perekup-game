# Перекуп: с 500 ₽ до миллиона

Первая полностью играбельная MVP-версия браузерной мобильной игры. Игрок начинает с 500 ₽, ищет недооценённые вещи, торгуется, улучшает покупки и перепродаёт их дороже.

## Установка

Нужен Node.js 20 или новее.

```bash
npm install
```

## Локальный запуск

```bash
npm run dev
```

Vite напечатает адрес в терминале. По умолчанию игру можно открыть по адресу:

```text
http://127.0.0.1:5173
```

Игра рассчитана в первую очередь на телефон, но адаптируется под планшет и компьютер.

## Production-сборка

```bash
npm run build
```

Готовые статические файлы появятся в папке `dist`.

Чтобы локально проверить именно production-сборку:

```bash
npm run preview
```

## Тесты

```bash
npm test
```

## Сохранение

Прогресс автоматически сохраняется в `localStorage` браузера под ключом `perekup-save-v1` после каждой покупки, продажи, улучшения и другого важного действия. После обновления страницы баланс, товары, предложения, статистика и обучение восстанавливаются.

Сбросить сохранение можно кнопкой «Начать игру заново» в разделе «Профиль».

## Что уже реализовано

- старт с балансом 500 ₽ и короткое пошаговое обучение;
- четыре раздела: объявления, мои товары, сообщения и профиль;
- 50 шаблонов товаров в постепенно открывающихся категориях;
- разнообразная лента без заметных повторов и витрина дорогих будущих сделок под замком;
- генерация плохих, обычных, выгодных и редких супервыгодных сделок;
- скрытая рыночная стоимость и четыре состояния товара;
- срочные объявления с таймером и повышенным риском дефекта;
- торг с продавцом: согласие, отказ и встречная цена;
- скрытые дефекты и проверка товара перед покупкой;
- чистка, мелкий ремонт, хороший ремонт и хорошие фотографии;
- собственная цена при публикации товара;
- разные типы покупателей, предложения и встречный торг;
- итог сделки с расходами, чистой прибылью и ROI;
- уровни, этапы пути до миллиона, статистика и открытие дорогих категорий;
- тестовые rewarded-механики без настоящей рекламы;
- анимации денег, реакции на прибыль и убыток, адаптивный mobile-first интерфейс;
- автоматическое локальное сохранение.

## Следующий этап

Следующим этапом подключается Yandex Games SDK. Для этого уже выделен адаптер `src/platform.js`: локальное сохранение можно заменить облачным, а тестовую функцию rewarded-рекламы — вызовом `ysdk.adv.showRewardedVideo()`. Также можно добавить авторизацию игрока, лидерборды, достижения и события аналитики, не меняя игровое ядро.
